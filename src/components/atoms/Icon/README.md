# Icon

Ícones visuais do conjunto Lucide.

## Contrato

name: IconName, size?: number, className?: string.

## Estados e variantes

estático; nome limitado à união exportada.

## Exemplo

```tsx
<Icon name="earth" size={24} />
```

## Acessibilidade e responsabilidade

Decorativo: aria-hidden e focusable=false; o controle pai fornece o nome acessível.
