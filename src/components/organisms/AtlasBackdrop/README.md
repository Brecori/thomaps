# AtlasBackdrop

Ilustração estática do mapa para a revisão visual.

## Contrato

Sem props. SVG externo derivado de Natural Earth pelo script assets:map-preview.

## Estados e variantes

estático; não seleciona nem aplica zoom.

## Exemplo

```tsx
<AtlasBackdrop />
```

## Acessibilidade e responsabilidade

role=img com descrição que explicita prévia; legendas são decorativas. O motor WorldMap entra em T05.
