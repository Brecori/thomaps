# CountryDetails

Região não modal do país de exemplo.

## Contrato

country: CountrySummary; onClose().

## Estados e variantes

aberto, rolagem interna e fechamento. Áudio indisponível.

## Exemplo

```tsx
<CountryDetails country={previewCountry} onClose={onClose} />
```

## Acessibilidade e responsabilidade

Nome por aria-labelledby; botão de fechar visível. Página devolve foco ao acionador. Não cria serviço de áudio.
