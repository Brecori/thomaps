# MediaCredits

Molécula de informação secundária para o responsável. Recebe uma gravação disponível e apresenta título, autoria, fonte, licença e aviso de conversão. Não carrega mídia. O `details` nativo abre por teclado/toque; links externos têm rótulos explícitos.

Exemplo: `<MediaCredits media={country.anthem} />` após verificar `status === 'available'`.
